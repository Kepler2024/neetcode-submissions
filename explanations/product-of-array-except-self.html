除自身以外数组的乘积

Products of Array Except Self。这一页从“数组是什么”讲起，一路走到 O(n) 时间、O(1) 额外空间的最优解。每一章只讲一个前置知识，读完最后一章你应该能闭着眼睛写出代码。

题目

给你一个整数数组 nums，返回一个数组 output，其中 output[i] 等于 nums 中除 nums[i] 以外所有元素的乘积。

进阶要求：时间复杂度 O(n)，并且不能使用除法。

输入: nums = [1,2,4,6] 输出: [48,24,12,8] 输入: nums = [-1,0,1,2,3] 输出: [0,-6,0,0,0]

约束：2 ≤ nums.length ≤ 10⁵，-30 ≤ nums[i] ≤ 30，任意前缀积或后缀积都能放进 32 位整数。

01

数组、下标与遍历

数组是一排连续的格子，每个格子有一个下标（从 0 开始）。长度为 n 的数组，下标是 0, 1, …, n-1。

这道题会用到两种遍历方向：

  • 从左往右：for i in range(n)，i 依次是 0, 1, …, n-1。
  • 从右往左：for i in range(n - 1, -1, -1)，i 依次是 n-1, …, 1, 0。range(起点, 终点, 步长) 不包含终点，所以终点写 -1 才能走到 0。

对于任意位置 i，数组被它切成三段：左边（下标 0 到 i-1）、它自己、右边（下标 i+1 到 n-1）。拖动滑块看看：

注意边界：i = 0 时左边是空的，i = n-1 时右边是空的。空的部分怎么算乘积？下一章回答。

02

乘法的三个性质

① 1 是乘法的“起点”

求和时我们从 0 开始累加，因为 x + 0 = x。求乘积时从 1 开始累乘，因为 x × 1 = x。所以空的一段，乘积规定为 1。这就解决了上一章的边界：i = 0 时左边乘积是 1。

② 乘法可以拆开再拼

乘法满足结合律和交换律，顺序随便换、随便分组，结果不变。因此：

除 nums[i] 外的乘积 = (左边所有数的乘积) × (右边所有数的乘积)

这一行就是整道题的核心思想。后面所有内容都是在教你怎么快速求出每个位置的左乘积和右乘积。

③ 0 会“吞掉”一切

任何数乘以 0 都是 0。如果数组里有 0，那么“包含这个 0 的乘积”全是 0。这正是例 2 的输出里大部分都是 0 的原因：只有 0 自己的位置（下标 1）能“跳过”这个 0，得到 -1 × 1 × 2 × 3 = -6。

负数也不需要特殊处理：负负得正，正常相乘就行。

03

时间与空间复杂度

时间复杂度描述“数组变长时，运算次数怎么增长”。O(n) 表示运算次数和 n 成正比；O(n²) 表示和 n 的平方成正比，两层嵌套循环通常就是 O(n²)。

空间复杂度描述“额外用了多少内存”。这道题约定：返回的 output 数组不算额外空间。所以如果除了 output 只用了几个变量，就叫 O(1) 额外空间。

O(n²) 暴力
O(n) 两遍

条长按对数刻度画。n = 10⁵（题目上限）时，暴力约 10¹⁰ 次乘法，会超时；两遍扫描只要约 2×10⁵ 次。

04

暴力解与除法陷阱

暴力：对每个 i，把其他数全乘一遍

for i in range(n):
    prod = 1
    for j in range(n):
        if j != i:          # 跳过自己
            prod *= nums[j]
    res[i] = prod

思路正确，但两层循环是 O(n²)。问题出在重复劳动：算 res[3] 时要乘 nums[0]×nums[1]×nums[2]，算 res[4] 时又从头乘一遍 nums[0]×nums[1]×nums[2]×nums[3]。

除法：先求总积，再除以自己？

直觉做法是 total = 所有数之积，然后 res[i] = total / nums[i]。它有两个问题：

  • 题目明确禁止除法。
  • 遇到 0 就崩：nums = [-1,0,1,2,3] 的总积是 0，0 / 0 无意义，而正确答案 res[1] 是 -6。

消除重复劳动的标准工具叫前缀：把“左边的乘积”边走边存下来，下一个位置直接在上一个结果上再乘一个数。

05

递推式：用上一项算下一项

递推式（recurrence）是一种描述一串数的方法。它不直接告诉你第 i 项是多少，而是告诉你两件事：

  • 初始值：第一项是多少。
  • 递推规则：怎样用前一项算出后一项。

有了这两样，就能像推多米诺骨牌一样，从第一块开始一块接一块地推下去。

先看三个最简单的例子

数列初始值递推规则算出来的前几项
自然数a[0] = 0a[i] = a[i-1] + 10, 1, 2, 3, 4
2 的幂b[0] = 1b[i] = b[i-1] × 21, 2, 4, 8, 16
阶乘f[0] = 1f[i] = f[i-1] × i1, 1, 2, 6, 24

怎么读：b[i] = b[i-1] × 2 念作“第 i 项等于前一项乘 2”。下标里的 i-1 就是“前一个”的意思，i+1 就是“后一个”。

动手算一次 2 的幂：b[0] = 1 是给定的；b[1] = b[0] × 2 = 2；b[2] = b[1] × 2 = 4；b[3] = b[2] × 2 = 8。每一步只看前一项，不需要回头看更早的数。

为什么递推能省时间

不用递推，算 6 的阶乘要做 1×2×3×4×5×6，乘 5 次；接着算 7 的阶乘又要从头乘 6 次。用递推，f[7] = f[6] × 7 只要 1 次，因为 f[6] 已经把前面全部乘好了。

递推的本质是复用上一步的结果。第 04 章暴力解的毛病正是“每个位置都从头乘一遍”，递推正好治这个病。

怎样自己推出递推式：展开、对比、找差

这道题需要每个位置的左乘积，记作 L[i]，意思是 i 左边所有数的乘积（不含 nums[i] 自己）。我们用三步推出它的递推式。

  1. 展开：按定义把 L[i] 写开。
    L[i] = nums[0] × nums[1] × … × nums[i-2] × nums[i-1]
  2. 写出前一项：把 i 换成 i-1，最右边一项就变成 nums[i-2]。
    L[i-1] = nums[0] × nums[1] × … × nums[i-2]
  3. 对比找差：两行一比，L[i] 只比 L[i-1] 多了最后一个因子 nums[i-1]。
    L[i] = L[i-1] × nums[i-1]
  4. 补上初始值：L[0] 是“下标 0 左边的乘积”，左边什么都没有，空乘积为 1（第 02 章）。
    L[0] = 1

用具体数字再验证一遍，取 i = 3：L[3] = nums[0] × nums[1] × nums[2]，L[2] = nums[0] × nums[1]，所以 L[3] = L[2] × nums[2]。和公式里把 i 换成 3 的结果一致。

下标为什么是 nums[i-1]，不是 nums[i]

因为 L[i] 不含自己，它最右边的因子是 i 左边紧挨着的 nums[i-1]。如果写成 X[i] = X[i-1] × nums[i]，得到的是包含自己的前缀积，是另一个东西：

i0123
nums[i]1246
包含自己 X[i]12848
不含自己 L[i]1128

能看出 L 就是 X 整体右移一格，前面补一个 1。写递推式时，先想清楚“这一项到底包含哪些数”，下标就不会错。

从递推式到代码

递推式几乎可以一字不改地翻译成循环。初始值写在循环前，递推规则写在循环里：

L = [1] * n                         # 初始值 L[0] = 1
for i in range(1, n):               # 从第 1 项开始推
    L[i] = L[i - 1] * nums[i - 1]   # 递推规则

再观察一下：算 L[i] 时只用到了 L[i-1]，更早的项以后再也用不到。既然只需要“上一项”，就不必存整个数组，一个变量就够了：

prefix = 1                # prefix 表示当前的 L[i]，从 L[0] = 1 开始
for i in range(n):
    res[i] = prefix       # 记下 L[i]
    prefix *= nums[i]     # 推进到 L[i+1] = L[i] * nums[i]

第二段里乘的是 nums[i] 而不是 nums[i-1]，这不矛盾。这一步是从 L[i] 推到 L[i+1]，把 i+1 代入递推式：L[i+1] = L[i] × nums[(i+1)-1] = L[i] × nums[i]。两段代码是同一个递推式，只是循环变量站的位置不同。最优解里的 prefix 变量就是这么来的。

这个“只依赖上一项，就用一个变量滚动”的技巧叫滚动变量（也叫状态压缩），以后做动态规划会经常用到。

反方向的递推

右乘积 R[i] 是 i 右边所有数的乘积。同样“展开、对比、找差”：R[i] = nums[i+1] × … × nums[n-1]，R[i+1] = nums[i+2] × … × nums[n-1]，差一个 nums[i+1]。

R[i] = R[i+1] × nums[i+1]　　初始值 R[n-1] = 1

这次 R[i] 依赖的是右边的 R[i+1]，所以必须先算出右边，也就是从右往左推。规律是：递推式依赖哪一边，就从那一边开始算。

06

前缀积：左边的乘积

你可能见过前缀和：prefixSum[i] 表示前 i 个数的和。前缀积是同一个想法，只是把加法换成乘法。

这道题我们要的是不含自己的左乘积，记作 L[i]：

L[i] = nums[0] × nums[1] × … × nums[i-1]　　（L[0] = 1，空乘积）

上一章推出的递推式：L[i] = L[i-1] × nums[i-1]。每个位置只需一次乘法，整趟 O(n)。

用 nums = [1, 2, 4, 6] 手算一遍：

i0123
nums[i]1246
L[i]111×2 = 22×4 = 8

写代码时常用一个“滚动变量” prefix：先把它写进当前位置，再乘上 nums[i]。这个先后顺序保证了“不含自己”。

07

后缀积：右边的乘积

完全对称：R[i] 是 i 右边所有数的乘积（不含自己），从右往左算。

R[i] = nums[i+1] × … × nums[n-1]　　（R[n-1] = 1）　　递推：R[i] = R[i+1] × nums[i+1]
i0123
nums[i]1246
R[i]48×1 = 486×4 = 2461
08

左 × 右 = 答案

回到第 02 章的核心公式：res[i] = L[i] × R[i]。在下面输入任意数组，三行会自动算出来（试试含 0 或负数的数组）：

这已经是 O(n) 时间的正确解法了：一趟算 L，一趟算 R，一趟相乘。但它额外开了 L 和 R 两个数组，额外空间 O(n)。下一章把它压到 O(1)。

09

最优解：O(1) 额外空间

两个观察：

  • L 数组可以直接存在 res 里。res 本来就要返回，不算额外空间。
  • R 不需要存成数组。从右往左走时，用一个变量 suffix 记住“当前位置右边的乘积”，边走边乘进 res[i]。

于是算法只有两趟：

  1. 第一趟（左 → 右）：res[i] = prefix，然后 prefix *= nums[i]。结束后 res[i] = L[i]。
  2. 第二趟（右 → 左）：res[i] *= suffix，然后 suffix *= nums[i]。结束后 res[i] = L[i] × R[i]。

class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        n = len(nums)
        res = [1] * n

        prefix = 1                      # 空乘积
        for i in range(n):              # 左 → 右
            res[i] = prefix             # 先写入：res[i] = L[i]
            prefix *= nums[i]           # 再把自己乘进去

        suffix = 1
        for i in range(n - 1, -1, -1):  # 右 → 左
            res[i] *= suffix            # res[i] = L[i] * R[i]
            suffix *= nums[i]

        return res


class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] res = new int[n];

        int prefix = 1;
        for (int i = 0; i < n; i++) {
            res[i] = prefix;
            prefix *= nums[i];
        }

        int suffix = 1;
        for (int i = n - 1; i >= 0; i--) {
            res[i] *= suffix;
            suffix *= nums[i];
        }
        return res;
    }
}


class Solution {
public:
    vector<int> productExceptSelf(vector<int>& nums) {
        int n = nums.size();
        vector<int> res(n, 1);

        int prefix = 1;
        for (int i = 0; i < n; i++) {
            res[i] = prefix;
            prefix *= nums[i];
        }

        int suffix = 1;
        for (int i = n - 1; i >= 0; i--) {
            res[i] *= suffix;
            suffix *= nums[i];
        }
        return res;
    }
};
