最长重复字符替换

Longest Repeating Character Replacement。先把题目翻译成一句话：一段子串里，留下出现最多的那个字母，其余的都换掉，换的个数不超过 k，这段就行。然后用暴力解把所有子串摆出来，从表格里看出一条规律，由它引出滑动窗口：r 往右扩，窗口不合法了 l 就往右收。最后讲 NeetCode 最优解里最反直觉的一步：记最多次数的 maxf 只增不减，为什么答案还是对的。

题目

给你一个只包含大写英文字母的字符串 s 和一个整数 k。你最多可以选 k 个字符，把每个都换成任意别的大写字母。

做完至多 k 次替换后，返回只包含一种字母的最长子串的长度。

输入: s = "XYYX", k = 2 输出: 4 解释: 把两个 X 换成 Y，或者把两个 Y 换成 X，整串都一样 输入: s = "AAABABB", k = 1 输出: 5 解释: 把下标 3 的 B 换成 A，得到 "AAAAABB"，前 5 个都是 A

约束：1 ≤ s.length ≤ 100,000，0 ≤ k ≤ s.length，s 只包含大写英文字母。

01

一段要换几个字母

子串是字符串里连续的一段。比如 "AABABBA" 里下标 1 到 4 的子串是 "ABAB"。跳着取的 "AAA"（下标 0、1、3）不算子串。

拿到一段子串，想把它变成同一个字母，最少要换几个？只需要决定留下哪个字母。留下 X，就要把所有不是 X 的都换掉，一共换 长度 − X 的次数 个。X 出现得越多，要换的越少，所以留下出现最多的那个：

最少要换几个 = 子串长度 − 子串里出现最多的字母的次数

这个数 ≤ k，这段就能变成同一个字母，下面把这样的子串叫合法的。题目问的就是：最长的合法子串有多长。

点一个字母当一端，再点一个当另一端，选出一段。下面的表列出留下每种字母各要换几个：

题目没让你真的去换，也不用说换成哪个字母、换哪几个位置。判断一段合不合法，只要数两个数：长度、出现最多的次数，一减，再和 k 比。

02

暴力解：试遍每一段

最直接的办法：枚举每一段子串，起点 i，终点 j（j ≥ i），算它要换几个，合法就用长度更新答案。

res = 0
for i in range(len(s)):                 # i：子串起点
    count = {}                          # 这一段里每个字母出现几次
    maxf = 0                            # 这一段里出现最多的次数
    for j in range(i, len(s)):          # j：子串终点，从 i 开始
        count[s[j]] = 1 + count.get(s[j], 0)
        maxf = max(maxf, count[s[j]])
        if (j - i + 1) - maxf <= k:     # 要换的个数不超过 k
            res = max(res, j - i + 1)
return res
  • count = {} 是一个空字典，按 key 存值。这里 key 是字母，值是它出现了几次，比如 {'A': 3, 'B': 1}。
  • count.get(s[j], 0)：字典里有这个字母就返回它的次数，没有就返回 0。所以 count[s[j]] = 1 + count.get(s[j], 0) 就是“这个字母的次数加一”，第一次出现时从 0 加到 1。
  • j 每往右一格，这一段就多一个字母 s[j]，只有 s[j] 的次数变了，所以 maxf = max(maxf, count[s[j]]) 就能更新最多次数。这里只加不减，maxf 一定是对的。第 06 章还会见到这一行。
  • 子串 [i, j] 两端都包含，长度是 j - i + 1，不是 j − i。
  • 一共 n(n + 1) / 2 段，时间 O(n²)。n 最大 10 万，要试约 50 亿段，会超时。

03

合法子串的规律

从上一章的表格里能看出一条规律，滑动窗口就是靠它把 O(n²) 降到 O(n) 的。先看一个事实：

合法的一段，去掉一头的一个字母，还是合法的。

去掉一个字母，长度少 1；出现最多的次数要么不变，要么也少 1。两种情况下“长度 − 最多次数”都不会变大，所以要换的个数不会变多。反过来说：不合法的一段，往外加字母，还是不合法。

按列看表格。第 r 列的右端固定是 r，从对角线往上走，起点 l 变小，段变长，要换的个数只增不减。所以每一列的绿色格子是从对角线往上连成一片的，到某一行为止，再往上全不合法。这一片最上面的那一格，起点叫做“最小合法 l”，它就是以 r 结尾的最长合法子串。

再看相邻两列。如果 [l, r + 1] 合法，去掉最右边的字母，[l, r] 也合法。所以第 r + 1 列的最小合法 l，不会比第 r 列的更小（更靠上）。紫框是每列的最小合法 l，连起来是一道往右下走的台阶：

合法：要换的 ≤ k每列最上面的绿格：最小合法 l
右端 r最小合法 l以 r 结尾的最长合法子串长度

r 往右走一格，最小合法 l 只会不动或往右走，永远不用往回退。所以不用每一列都从对角线重新往上找：沿着台阶，r 走一遍、l 也只往右走一遍，就能把每列的最长合法子串都找出来。答案是表格最后一列里最大的长度。

04

滑动窗口：r 扩，l 收

把 [l, r] 叫做一个窗口。r 每轮往右扩一格，把一个新字母放进窗口；窗口不合法了，就从左边把字母移出去，l 往右收，直到合法为止。这就是沿着上一章的台阶走。

count = {}                      # 窗口 [l, r] 里每个字母出现几次
res = 0
l = 0
for r in range(len(s)):
    count[s[r]] = 1 + count.get(s[r], 0)                # s[r] 进窗口
    while (r - l + 1) - max(count.values()) > k:     # 要换的超过 k 个
        count[s[l]] -= 1                                # s[l] 出窗口
        l += 1
    res = max(res, r - l + 1)
return res
  • for r in range(len(s))：r 依次是 0、1、……、n − 1。range(n) 给出 0 到 n − 1，不含 n。
  • count.values() 是字典里所有的次数，max(count.values()) 取最大的，就是窗口里出现最多的字母的次数。所以 while 的条件就是第 01 章那个公式：窗口长度 − 最多次数 > k，要换的太多。
  • 收缩两步：count[s[l]] -= 1，最左边的字母离开窗口，次数减一；l += 1，左端往右一格。x -= 1 就是 x = x - 1。
  • while 结束时 [l, r] 合法，而且 l 是从上一轮的位置开始收的，第一个合法的位置就停，所以 [l, r] 正好是“以 r 结尾的最长合法子串”，也就是台阶上那一格。用它的长度 r - l + 1 更新 res。
  • 字母的次数减到 0 之后还留在字典里，值是 0，不影响 max。

也可以不用字典，用长度 26 的列表：count = [0] * 26，字母 c 存在 count[ord(c) - ord('A')]。ord 返回字母的编号，'A' 是 65，'B' 是 66，减去 ord('A') 就落在 0 到 25。Java、C++ 版本都是这么写的。

为什么是 O(n)

  • r 从 0 走到 n − 1，一共 n 步。l 只往右走，最多也走 n 步，所以 while 里面的收缩加起来最多 n 次，不是每轮 n 次。
  • 每次判断 while 条件要算一次 max(count.values())，最多看 26 个字母。所以总时间 O(26 · n)，也就是 O(n)。

这个 26 是常数，复杂度上不算。但每次都看一遍 26 个字母还是浪费，第 06 章会把它去掉。

06
maxf 为什么不用往回减

  
写法一每判断一次 while 条件，都要把 26 个字母看一遍找最大值。能不能像暴力解那样，用一个变量 maxf 记住“出现最多的次数”？

  
    
    
  • 加字母时很容易：只有 s[r] 的次数变大了，maxf = max(maxf, count[s[r]]) 就行。
    • 
    
  • 减字母时麻烦：s[l] 的次数减一以后，最多次数可能少 1，也可能不变（别的字母一样多），要重新找。
    • 
  

  
NeetCode 的最优解干脆不管第二种情况：maxf 只增不减。


count = {}
res = 0
l = 0
maxf = 0                        # 出现最多的次数，只增不减
for r in range(len(s)):
    count[s[r]] = 1 + count.get(s[r], 0)
    maxf = max(maxf, count[s[r]])
    while (r - l + 1) - maxf > k:
        count[s[l]] -= 1        # 次数照样减，但 maxf 不动
        l += 1
    res = max(res, r - l + 1)
return res

  
这样一来 maxf 经常比窗口里真实的最多次数大，代码算出的“要换几个”偏小，有时会放过一个其实不合法的窗口。可返回的答案还是对的。分三步看：


  
1. 窗口从不变短

  
每轮开始前，上一轮已经保证了 len − maxf ≤ k。r 右移一格：len 加 1，maxf 不变或加 1，所以 len − maxf 最多变成 k + 1。超了就收一格：len 减回原来的值，maxf 不动，又回到 ≤ k。

  
所以写法二的 while 最多跑一次，写成 if 也一样。窗口长度每轮要么加 1，要么不变，从不缩短，它一直等于 res。


  
2. 答案不会偏小

  
maxf 只会比真实的最多次数大，不会小：每个字母的次数变大时，maxf 都跟着更新过；之后次数只会减，maxf 不减。所以代码算出的要换个数 ≤ 真实要换的个数，真正合法的窗口，代码一定放行。

  
窗口想从长度 L 长到 L + 1 时，这一轮检查的正是“以 r 结尾、长度 L + 1”的那一段。只要它真的合法，窗口就一定能长上去。设最长的合法子串是 [a, b]，它的每一段前缀 [a, r] 都合法（合法的段去掉一头还合法）。r 从 a 走到 b 的每一轮，窗口要么已经不比 [a, r] 短，要么上一轮正好和 [a, r − 1] 一样长，这一轮检查的就是 [a, r]，它合法，于是长一格追上。r 走到 b 时，窗口长度至少是 b − a + 1。


  
3. 答案不会偏大

  
while 保证了窗口长度永远 ≤ maxf + k。maxf 是某一轮窗口里某个字母真实出现的次数：maxf 变大的那一轮，len 和 maxf 都加了 1，len − maxf 没变，while 不会执行，所以那一轮的窗口真的合法，里面有 maxf 个相同的字母，长度 ≤ maxf + k。把它往两边扩到长度 maxf + k（不超过 s 的长度），扩进来的字母都换掉，要换的个数还是 ≤ k。所以长度 maxf + k 的合法子串真实存在，res 不会超过真正的答案。


  
一句话：答案要变长，必须出现比以前更多的相同字母，所以只需要盯住 maxf 什么时候变大。它该变小的时候，窗口反正不会缩短，不用管。去掉了每次 26 个字母的 max，时间是严格的 O(n)。

“最长的、满足某个条件的连续子串”，几乎都是同一个骨架：


l = 0
for r in range(len(s)):
    把 s[r] 加进窗口                # 更新计数
    while 窗口不合法:
        把 s[l] 移出窗口            # 计数也要跟着减

写法二：maxf 只增不减（NeetCode 最优解）


class Solution:
    def characterReplacement(self, s: str, k: int) -> int:
        count = {}
        res = 0
        l = 0
        maxf = 0
        for r in range(len(s)):
            count[s[r]] = 1 + count.get(s[r], 0)
            maxf = max(maxf, count[s[r]])
            while (r - l + 1) - maxf > k:
                count[s[l]] -= 1
                l += 1
            res = max(res, r - l + 1)
        return res

写法二：maxf 只增不减（NeetCode 最优解）


class Solution {
    public int characterReplacement(String s, int k) {
        int[] count = new int[26];       // count[0] 是 'A' 的次数，以此类推
        int l = 0, maxf = 0, res = 0;
        for (int r = 0; r < s.length(); r++) {
            count[s.charAt(r) - 'A']++;
            maxf = Math.max(maxf, count[s.charAt(r) - 'A']);
            while ((r - l + 1) - maxf > k) {
                count[s.charAt(l) - 'A']--;
                l++;
            }
            res = Math.max(res, r - l + 1);
        }
        return res;
    }
}

    
写法一：每次重算最多次数


class Solution {
    public int characterReplacement(String s, int k) {
        int[] count = new int[26];
        int l = 0, res = 0;
        for (int r = 0; r < s.length(); r++) {
            count[s.charAt(r) - 'A']++;
            while ((r - l + 1) - maxOf(count) > k) {
                count[s.charAt(l) - 'A']--;
                l++;
            }
            res = Math.max(res, r - l + 1);
        }
        return res;
    }

    private int maxOf(int[] count) {
        int m = 0;
        for (int c : count) m = Math.max(m, c);
        return m;
    }
}

  

  

    
写法二：maxf 只增不减（NeetCode 最优解）


class Solution {
public:
    int characterReplacement(string s, int k) {
        vector<int> count(26, 0);        // count[0] 是 'A' 的次数，以此类推

        for (int r = 0; r < (int)s.size(); r++) {
            count[s[r] - 'A']++;
            maxf = max(maxf, count[s[r] - 'A']);
            while ((r - l + 1) - maxf > k) {
                count[s[l] - 'A']--;
                l++;
            }
            res = max(res, r - l + 1);
        }
        return res;
    }
};

    
写法一：每次重算最多次数


class Solution {
public:
    int characterReplacement(string s, int k) {
        vector<int> count(26, 0);
        int l = 0, res = 0;
        for (int r = 0; r < (int)s.size(); r++) {
            count[s[r] - 'A']++;
            while ((r - l + 1) - *max_element(count.begin(), count.end()) > k) {
                count[s[l] - 'A']--;
                l++;
            }
            res = max(res, r - l + 1);
        }
        return res;
    }
};

  

  
class Solution: 和 def characterReplacement(self, s: str, k: int) -> int: 是 NeetCode 给定的外壳。str、int 和 -> int 是类型提示，表示参数和返回值的类型，不影响运行。Java 的 s.charAt(r) - 'A' 和 Python 的 ord(s[r]) - ord('A') 是一回事。


  
复杂度

  

    
解法时间额外空间说明

    
暴力：试遍每一段O(n²)O(1)n(n + 1) / 2 段

    
写法一：重算最多次数O(26 · n)O(1)l、r 各走一遍，每次判断看 26 个字母

    
写法二：maxf 只增不减O(n)O(1)每轮 O(1)

  

  
额外空间是 O(1)：count 最多 26 个字母，不随 n 变大。


  
最容易写错的四个地方

  
    
    
  • 收缩时漏写 count[s[l]] -= 1：离开窗口的字母还被算在里面，最多次数偏大，窗口被放得太长。"AABABBA", k=1 返回 5，正确是 4。两个样例却都能过。
    • 
    
  • 用 count[s[r]] 代替最多次数：刚进来的字母不一定是最多的。"AAB", k=1 走到 B 时算成要换 3 − 1 = 2 个，把窗口收短了，返回 2，正确是 3（把 B 换成 A）。
    • 
    
  • 长度写成 r - l：[l, r] 两端都包含，长度是 r − l + 1。
    • 
    
  • 用写法二的窗口当答案子串：maxf 过时的时候，窗口可能不合法，它只有长度是对的。
    •
