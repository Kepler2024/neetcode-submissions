反转链表

Reverse Linked List。先讲清楚链表是什么，以及“挪变量”和“改箭头”是两件不同的事。然后把题目翻译成一句话：节点都不动，每根箭头掉个头。最后用三个指针 prev、curr、nxt 一次翻一根箭头，再看递归写法里那行最绕的 head.next.next = head。

题目

给你单链表的头节点 head，把链表反转过来，返回反转后链表的头节点。

输入: head = [0,1,2,3] 输出: [3,2,1,0] 输入: head = [] 输出: []

约束：链表长度 0 到 1000，−1000 ≤ Node.val ≤ 1000。

01

链表是什么

数组把元素挨着放在一整块内存里，所以能用下标 a[2] 直接跳到第 3 个。链表不是这样：每个元素是一个单独的节点，散在内存各处，节点里除了值，还存着“下一个节点在哪”。

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val      # 这个节点存的值
        self.next = next    # 下一个节点；没有下一个就是 None
  • 每个节点有两样东西：val 是值，next 指向下一个节点。下面的图里，节点画成方框，next 画成箭头。
  • 最后一个节点的 next 是 None，表示到头了。
  • head 是指向第一个节点的变量。题目只给你 head，其它节点都要顺着箭头一个一个走过去才能拿到。
  • 空链表就是 head = None，一个节点都没有（题目的样例 2）。
  • 题目里写的 [0,1,2,3] 只是方便你看，实际传进来的是节点 0，0 → 1 → 2 → 3 → None。

02
挪变量 vs 改箭头

  
链表题几乎所有的 bug 都出在分不清这两种赋值。看等号左边是什么：

  

    
写法改了什么链表变没变

    
a = a.next变量 a 改成指向下一个节点。变量只是贴在节点上的名字标签，这一步只是把标签挪了没变

    
a.next = Nonea 指着的那个节点，它里面的 next 被改了，也就是这个节点的箭头改了变了

  

  
箭头一改，原来箭头指着的节点就可能丢了：没有任何变量指着它，也没有任何箭头通向它，再也拿不到。所以改箭头之前，要先想好：后面的节点还有没有别人指着？没有就先用一个变量把它记下来。

03
笨办法：先抄到数组里

  
链表不能往回走，但数组可以。最直接的想法：先走一遍，把值都抄进数组；再走一遍，从数组末尾往回填。


vals = []
cur = head
while cur:                  # 第一遍：把值按顺序抄下来
    vals.append(cur.val)
    cur = cur.next
cur = head
while cur:                  # 第二遍：从最后一个值开始往回填
    cur.val = vals.pop()    # pop() 取出并删掉数组最后一个
    cur = cur.next
return head

  
    
    
  • 能过，时间 O(n)。但多开了一个长度 n 的数组，额外空间 O(n)。
    • 
    
  • 它改的是节点里的值，节点和箭头都没动。题目真正想考的是改箭头：如果节点里存的不是一个数，而是一大坨数据，挨个搬值就很笨。面试官一般会追问“能不能 O(1) 额外空间”。
    •

每根箭头掉个头

  
把反转前后画在一起看。节点一个都没动，变的只有箭头：

  

    
反转前

    

    
反转后

    

    
原来的方向掉过头的箭头

  

  
所以题目可以翻译成：每个节点的 next，改成指向它原来的前一个节点。第一个节点没有前一个，改成指向 None；原来最后一个节点 3 就成了新的头，要返回它。

  
从左往右，一次改一个节点。改到一半的时候，链表被分成两段：

  

    

    

  

  
    
    
  • prev：已经改好的那一段的头。从它出发读，是反过来的前半段。
    • 
    
  • curr：下一个要改的节点。从它出发读，是还没动过的后半段。
    • 
    
  • nxt：curr 后面那个节点。curr 的箭头马上要改掉，改之前得先把它存下来（第 02 章那句话）。
    • 
  

  
处理 curr 一共四行，顺序不能换：

  

    
代码做什么为什么在这个位置

    
nxt = curr.next存下 curr 后面的节点下一行就要改 curr.next，不先存，后半段就丢了

    
curr.next = prevcurr 的箭头掉头，指向前一个这是唯一真正“反转”的一行

    
prev = currprev 往前走一格要在 curr 被改掉之前，用 curr 的值

    
curr = nxtcurr 往前走一格用的是第一行存的 nxt，不能写 curr.next，它已经指回去了

  

  
开始时还没有改好的部分，prev = None，curr = head。这正好让第一个节点的箭头指向 None。curr 变成 None 时，所有节点都改完了，prev 停在原来的最后一个节点上，返回 prev。


prev, curr = None, head
while curr:
    nxt = curr.next      # 1. 先存后面
    curr.next = prev     # 2. 箭头掉头
    prev = curr          # 3. prev 前进
    curr = nxt           # 4. curr 前进
return prev

  
prev, curr = None, head 是 Python 的一次给两个变量赋值，等于 prev = None 再 curr = head。NeetCode 视频里把 nxt 叫做 temp，是同一个东西。

06
递归写法

  
换个角度想：要反转 0 → 1 → 2 → 3，假如有人已经帮你把后面的 1 → 2 → 3 反好了，变成 3 → 2 → 1 → None，你还差什么？

  
只差把 0 接到 1 后面。而 0 的箭头这时还指着 1，所以 head.next 就是 1，head.next.next = head 就是“让 1 的箭头指向 0”。再把 0 的箭头改成 None，0 就成了新的尾巴。

  
“有人帮你反好后面”就是递归调用自己。一直往后递归，直到只剩一个节点：一个节点反转后还是它自己，直接返回。


def reverseList(head):
    if not head:                  # 空链表
        return None
    newHead = head                # 只有一个节点时，它自己就是新的头
    if head.next:
        newHead = reverseList(head.next)    # 先把后面那段反好
        head.next.next = head     # 后面那段的尾巴（原来的 head.next）指回 head
    head.next = None              # head 变成尾巴
    return newHead

  
    
    
  • head.next.next = head 从左往右读：head.next 是 head 后面的节点，再 .next 是那个节点的箭头，把它改成指向 head。
    • 
    
  • 反好的后半段，尾巴正好是原来的 head.next，所以不用从 newHead 一路走到尾巴去找它。
    • 
    
  • newHead 是原来最后一个节点，它在最深的一层被找到，然后每一层都原样往上传，没人改它。
    • 
    
  • 执行完 head.next.next = head 的那一刻，head 和后面那个节点互相指着，是一个小环。下一行 head.next = None 把它剪断。漏了这一行，最外层的 0 和 1 会一直互相指，链表就走不完了。
    •

07
反转模板与同类题

  
这四行是链表题里用得最多的一段代码，值得背下来：


prev, curr = None, head
while curr:
    nxt = curr.next      # 先存后面
    curr.next = prev     # 箭头掉头
    prev, curr = curr, nxt
# 结束时 prev 是新的头

  
很多题都是“找到一段，把它反过来，再接回去”：

  

    
题目反转用在哪

    
本题整条链表反转

    
Reorder List用快慢指针找到中点，后半段反转，再和前半段交替合并

    
Palindrome Linked List后半段反转，和前半段逐个比较

    
Reverse Linked List II只反转第 left 到第 right 个节点，反完要把两头接回去

    
Reverse Nodes in k-Group每 k 个节点反转一次，一段一段接起来

  

  
下次怎么想到

  
    
    
  1. 链表只能往后走。要“往回指”，就得自己用一个变量（prev）记住刚走过的节点。
    2. 
    
  2. 每改一根箭头，先问：箭头原来指着的节点，还有没有别的变量指着？没有就先存（nxt）。

  3. 画图。在纸上画出三四个节点，每执行一行就改一根箭头或挪一个标签，比在脑子里想可靠得多。

完整代码与复杂度

  

    
    
    
  

  

    
迭代（推荐）


class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        prev, curr = None, head
        while curr:
            nxt = curr.next
            curr.next = prev
            prev = curr
            curr = nxt
        return prev

    
递归


class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head:
            return None
        newHead = head
        if head.next:
            newHead = self.reverseList(head.next)
            head.next.next = head
        head.next = None
        return newHead

  

  

    
迭代（推荐）


class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode prev = null, curr = head;
        while (curr != null) {
            ListNode nxt = curr.next;
            curr.next = prev;
            prev = curr;
            curr = nxt;
        }
        return prev;
    }
}

    
递归


class Solution {
    public ListNode reverseList(ListNode head) {
        if (head == null) return null;
        ListNode newHead = head;
        if (head.next != null) {
            newHead = reverseList(head.next);
            head.next.next = head;
        }
        head.next = null;
        return newHead;
    }
}

  

  

    
迭代（推荐）


class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        ListNode* curr = head;
        while (curr != nullptr) {
            ListNode* nxt = curr->next;
            curr->next = prev;
            prev = curr;
            curr = nxt;
        }
        return prev;
    }
};

    
递归


class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        if (head == nullptr) return nullptr;
        ListNode* newHead = head;
        if (head->next != nullptr) {
            newHead = reverseList(head->next);
            head->next->next = head;
        }
        head->next = nullptr;
        return newHead;
    }
};

  

  
Optional[ListNode] 是类型提示，意思是“一个 ListNode 或者 None”，不影响运行。递归写法在类里要写 self.reverseList(...) 调用自己。Java 里的 null、C++ 里的 nullptr 就是 Python 的 None；C++ 用 -> 访问指针指着的节点的成员。


  
复杂度

  

    
解法时间额外空间说明

    
抄到数组再填回去O(n)O(n)数组存 n 个值，改的是值不是箭头

    
迭代：三个指针O(n)O(1)每个节点改一次箭头，只用 prev、curr、nxt 三个变量

    
递归O(n)O(n)调用栈有 n 层

  


  
最容易写错的四个地方

  
    
    
  • 没先存 curr.next：先写 curr.next = prev 再 curr = curr.next，curr 会退回 prev。[0,1,2,3] 只返回 [0]，后面的节点全丢了。
    • 
    
  • 返回 curr 或 head：循环结束时 curr 是 None；head 还指着原来的第一个节点，它已经是尾巴了。返回 head 得到的是 [0]。要返回 prev。
    • 
    
  • 递归漏写 head.next = None：原来的头节点 0 和节点 1 互相指着，形成环，链表走不完。
    • 
    
  • 递归不判断空链表：head = None 时直接访问 head.next 会报错，所以第一行要 if not head: return None。
    •
