合并两个有序链表

Merge Two Sorted Linked Lists。先复习“挪标签”和“改箭头”的区别，再从“两队人按身高排好，每次比两个排头”讲出合并的思路。然后讲哨兵节点 dummy 为什么能省掉一堆特判，一步一步看 tail 怎么把节点一个个接起来，最后看递归写法。

题目

给你两个已经从小到大排好序的链表的头节点 list1 和 list2。把它们合并成一个有序链表，返回新链表的头节点。新链表要由 list1 和 list2 原有的节点组成。

输入: list1 = [1,2,4], list2 = [1,3,5] 输出: [1,1,2,3,4,5] 输入: list1 = [], list2 = [1,2] 输出: [1,2] 输入: list1 = [], list2 = [] 输出: []

约束：每条链表长度 0 到 100，−100 ≤ Node.val ≤ 100。

01

复习：挪标签 vs 改箭头

链表的每个节点有两样东西：值 val，和指向下一个节点的 next（最后一个节点的 next 是 None）。题目只给你两个头节点，其它节点都要顺着 next 一个一个走过去才能拿到。

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val      # 这个节点存的值
        self.next = next    # 下一个节点；没有下一个就是 None

变量（list1、tail 这些）只是贴在节点上的名字标签。判断一行代码有没有改链表，看等号左边：

写法改了什么链表变没变
list1 = list1.nextlist1 这个标签挪到下一个节点没变
tail = tail.nexttail 这个标签挪到下一个节点没变
tail.next = list1tail 指着的那个节点，它的箭头改成指向 list1 指着的节点变了

这道题的代码里，真正改链表的只有 tail.next = ... 这一种行。其它行都是在挪标签。下面的图和单步执行都按这个分：箭头画成线，标签写在节点旁边。

本题不需要新建任何存值的节点。题目说“由原有的节点组成”，意思就是只改这些节点的箭头，把它们重新串成一条。

02

合并的想法：比两个排头

想象两队人，每队都已经按身高从矮到高站好。现在要把两队并成一队，还是从矮到高。

全场最矮的人在哪？一定是两个排头之一：每队排头都是本队最矮的。所以只要比一下两个排头，矮的那个出列，站到新队伍末尾。出列以后，他那队的第二个人变成新排头，再比，再出列……直到有一队空了，另一队剩下的人本来就排好了，整队接到末尾就行。

用样例 list1 = [1,2,4]、list2 = [1,3,5] 走一遍：

轮list1 剩下list2 剩下比较排头取谁结果
11,2,41,3,51 <= 1list1 的 11
22,41,3,52 > 1list2 的 11,1
32,43,52 <= 3list1 的 21,1,2
443,54 > 3list2 的 31,1,2,3
5454 <= 5list1 的 41,1,2,3,4
收尾空5list1 用完了list2 剩下的整段1,1,2,3,4,5
  • 每轮只比较一次，取走一个节点。两条一共 m + n 个节点，最多 m + n 轮，时间 O(m + n)。
  • 两个排头相等时取哪个都对。用 <= 就先取 list1 的，用 < 就先取 list2 的，输出的值完全一样。
  • 这个“比排头”的过程就是归并排序（merge sort）里“合并”那一步。数组版和链表版想法一样，区别只在怎么把元素放进结果。
03

笨办法：抄出来排序

不想动脑的话：把两条链表的值都抄进一个数组，排序，再按顺序建一条新链表。

vals = []
for cur in (list1, list2):
    while cur:                  # 把两条链表的值都抄下来
        vals.append(cur.val)
        cur = cur.next
vals.sort()                     # 排序：O((m+n) log(m+n))
dummy = ListNode()
tail = dummy
for v in vals:                  # 按顺序新建节点串起来
    tail.next = ListNode(v)
    tail = tail.next
return dummy.next
  • 能过，但排序要 O((m+n) log(m+n))，还多开了数组和一整套新节点，额外空间 O(m+n)。
  • 它完全没用上“两条已经排好序”这个条件。有序是题目白送的信息，用上它就能省掉排序，降到 O(m+n)。
  • 它建的是新节点，不符合“由原有节点组成”的要求（判题一般不查这个，但面试官会问）。

不过这段代码里已经出现了 dummy 和 tail。正解也用它们，下一章专门讲。

04

哨兵节点 dummy

合并时要一边比较一边往结果末尾接节点。麻烦在第一个节点：结果一开始是空的，没有“末尾”可接，只能单独处理，先找出谁是头，再进循环。不用 dummy 的写法长这样：

if not list1:                   # 先处理有空链表的情况
    return list2
if not list2:
    return list1
if list1.val <= list2.val:      # 单独选出结果的头
    head = list1
    list1 = list1.next
else:
    head = list2
    list2 = list2.next
tail = head
while list1 and list2:
    ...                         # 后面才是正常的“比较、接上”

选头的那段和循环里做的事几乎一样，只是因为“还没有末尾”被迫多写一遍。哨兵节点（dummy node）的办法是：先造一个假的节点放在最前面当车头。这样结果从一开始就有末尾了，第一个真节点也是“接在末尾后面”，和其它节点一视同仁。

dummy = ListNode()      # 假节点，值是默认的 0，我们不会去读它
tail = dummy            # tail：结果链表现在的最后一个节点
# ... 循环里每次：tail.next = 较小的排头，然后 tail = tail.next
return dummy.next       # 跳过假节点，后面才是真正的答案

合并完以后，链表长这样。左边虚线框是 dummy，橙色是 list1 原来的节点，蓝色是 list2 的。节点从左到右的位置就是它在答案里的位置：

list1 的节点（上排）list2 的节点（下排）结果链表的箭头
  • dummy 从头到尾都不动，一直指着那个假节点，所以最后能靠它找回结果的开头。
  • tail 一直在往后挪，永远停在结果的最后一个节点上，方便往后接。这和反转链表那页的 head 不动、cur 往后走是一回事。
  • 两条都是空链表时，循环一次都不进，dummy.next 还是 None，正好就是答案。不用任何特判。

记住一句话：要从零拼出一条链表，就先建一个 dummy。最后返回 dummy.next，不是 dummy。

05

一轮循环做三件事

while list1 and list2:          # 两条都还有节点，才需要比较
    if list1.val <= list2.val:
        tail.next = list1       # 1. 把较小的排头接到结果末尾
        list1 = list1.next      # 2. 那条链表的排头往后挪
    else:
        tail.next = list2
        list2 = list2.next
    tail = tail.next            # 3. tail 挪到刚接上的节点
代码做什么为什么
tail.next = list1改箭头：结果的最后一个节点指向较小的排头这是唯一真正改链表的一行
list1 = list1.next挪标签：list1 的排头往后一格这个节点已经进了结果，下一轮该比它后面的
tail = tail.next挪标签：tail 走到刚接上的节点它现在是结果的最后一个，下一个要接在它后面
  • 第 1、2 行的顺序可以换吗？不能先挪 list1：list1 = list1.next 之后，list1 已经指着下一个了，再 tail.next = list1 就接错了节点。
  • 第 3 行写成 tail = list1 也不行，因为这时 list1 已经挪走了。tail.next 才是刚接上的那个节点。
  • 循环条件是 and：只要有一条空了就停。如果写成 or，一条空了还进循环，list1.val 会在 None 上取值报错。

有个容易让人困惑的地方：节点被接进结果后，它自己的箭头还指着原来那条链表里的下一个。下图是样例跑完两轮的样子：

已经定下来的箭头还是原来的箭头

从 dummy.next 读出来是 1 → 1 → 3 → 5，好像漏了 2 和 4。其实只有绿色箭头那段是定下来的。tail 后面那根灰箭头是蓝色 1 在 list2 里原来的箭头，下一轮比较 2 和 3，会执行 tail.next = list1，把它改到 2 上。

不变的规律：每轮循环结束时，从 dummy.next 到 tail 这一段，正好是目前最小的那几个节点，已经排好。tail 之后的箭头暂时不算数。

07
收尾：接上剩下的

  
循环在“有一条空了”时停下。另一条可能还剩一段，这时只要一行：


tail.next = list1 or list2

  
Python 的 a or b：a 不是 None（算“真”）就得到 a，否则得到 b。循环结束时至少有一条是 None，所以这一行就是“哪条还有剩，就接哪条”：

  

    
循环结束时list1 or list2 得到效果

    
list1 有剩，list2 是 Nonelist1把 list1 剩下的整段接上

    
list1 是 None，list2 有剩list2把 list2 剩下的整段接上

    
两条都是 NoneNonetail.next = None，结果到此结束

  

  
不习惯 or 的话，写成 if/else 是一样的：


if list1:
    tail.next = list1
else:
    tail.next = list2

  
    
    
  • 为什么一行就够，不用再循环？剩下的节点本来就一个接一个连着，而且有序。接上它的第一个节点，后面的整段就跟着进来了。
    • 
    
  • 为什么直接接在后面是对的？每轮取的都是当时最小的，所以剩下的节点都不比已经取出的小，排在最后没问题。
    • 
    
  • 数组版合并要用循环把剩下的元素一个个复制过去；链表版只改一根箭头，这是链表的方便之处。
    • 
  

  
漏了这一行，结果会少一截：循环结束时 tail 是用完的那条链表的最后一个节点，它的 next 是 None，另一条剩下的就没接上（第 06 章可以切换试试）。







  
08
递归写法

  
换个角度想：合并结果的头是谁？就是两个排头里小的那个，比如 list1。它后面接什么？接“list1 去掉头以后”和“整个 list2”合并的结果，这是同一个问题，只是少了一个节点。


def mergeTwoLists(list1, list2):
    if not list1:               # list1 用完了，剩下的 list2 就是结果
        return list2
    if not list2:
        return list1
    if list1.val <= list2.val:
        list1.next = mergeTwoLists(list1.next, list2)   # 后面那段交给下一层
        return list1            # list1 是这一段的头
    else:
        list2.next = mergeTwoLists(list1, list2.next)
        return list2

  
    
    
  • 每一层只做一件事：选出这一段的头，把它的 next 接到“下一层返回的结果”上，再把自己返回给上一层。
    • 
    
  • 递归的终点是有一条空了，直接返回另一条，这就是迭代写法里收尾那一行。
    • 
    
  • 往下走的时候一根箭头都不改；所有 .next = ... 都发生在往回返的路上，从结果的最后面开始，一层层往前接好。
    • 
    
  • 不需要 dummy：每一层返回的就是头，没有“第一个节点”的特殊情况。
    •

09
合并模板与同类题

  
“dummy + tail”是拼链表的通用骨架，值得背下来：


dummy = ListNode()
tail = dummy
while 还有节点要接:
    node = 这一步要接的节点
    tail.next = node        # 接到末尾
    tail = tail.next        # 末尾往后挪
return dummy.next

  

    
题目和本题的关系

    
本题每次从两个排头里挑小的接上

    
Merge K Sorted Lists从 k 个排头里挑最小的，用最小堆加速挑选；或者两两调用本题

    
Sort List链表的归并排序：从中间切开，两半各自排好，再用本题合并

    
Add Two Numbers同样的 dummy + tail，每一位新建一个节点接上

    
Remove Nth Node From End用 dummy 放在最前面，删除头节点时就不用特判

    
Merge Sorted Array数组版合并，从后往前填，避免覆盖还没比较的元素

迭代（推荐，和你的提交一样）


class Solution:
    def mergeTwoLists(self, list1: Optional[ListNode], list2: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode()
        tail = dummy
        while list1 and list2:
            if list1.val <= list2.val:
                tail.next = list1
                list1 = list1.next
            else:
                tail.next = list2
                list2 = list2.next
            tail = tail.next
        tail.next = list1 or list2
        return dummy.next

迭代（推荐）


class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        ListNode dummy = new ListNode();
        ListNode tail = dummy;
        while (list1 != null && list2 != null) {
            if (list1.val <= list2.val) {
                tail.next = list1;
                list1 = list1.next;
            } else {
                tail.next = list2;
                list2 = list2.next;
            }
            tail = tail.next;
        }
        tail.next = (list1 != null) ? list1 : list2;
        return dummy.next;
    }
}

    
递归


class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        if (list1 == null) return list2;
        if (list2 == null) return list1;
        if (list1.val <= list2.val) {
            list1.next = mergeTwoLists(list1.next, list2);
            return list1;
        }
        list2.next = mergeTwoLists(list1, list2.next);
        return list2;
    }
}

  

  

    
迭代（推荐）


class Solution {
public:
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        ListNode dummy;
        ListNode* tail = &dummy;
        while (list1 != nullptr && list2 != nullptr) {
            if (list1->val <= list2->val) {
                tail->next = list1;
                list1 = list1->next;
            } else {
                tail->next = list2;
                list2 = list2->next;
            }
            tail = tail->next;
        }
        tail->next = (list1 != nullptr) ? list1 : list2;
        return dummy.next;
    }
};

    
递归


class Solution {
public:
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        if (list1 == nullptr) return list2;
        if (list2 == nullptr) return list1;
        if (list1->val <= list2->val) {
            list1->next = mergeTwoLists(list1->next, list2);
            return list1;
        }
        list2->next = mergeTwoLists(list1, list2->next);
        return list2;
    }
};

  

  
Optional[ListNode] 是类型提示，意思是“一个 ListNode 或者 None”。递归写法在类里要写 self.mergeTwoLists(...)。Java、C++ 没有 Python 那种 or 用法，用 条件 ? a : b（条件成立取 a，否则取 b）。C++ 里 ListNode dummy; 直接在函数里建一个节点，&dummy 取它的地址给 tail；它在函数结束时自动销毁，而返回的 dummy.next 指着的是原有的节点，不受影响。


  
复杂度（m、n 是两条链表的长度）

  

    
解法时间额外空间说明

    
抄出来排序再建新链表O((m+n) log(m+n))O(m+n)没用上“已经有序”

    
迭代：dummy + tailO(m+n)O(1)每个节点接一次，只多了一个 dummy 和几个变量

    
递归O(m+n)O(m+n)调用栈最多 m+n 层

  


  
最容易写错的五个地方

  
    
    
  • 漏写 tail = tail.next：tail 一直停在 dummy 上，每轮都在改 dummy.next，前面接的节点全被挤掉。[1,2,4] + [1,3,5] 只返回 [5]。
    • 
    
  • 漏写最后的 tail.next = list1 or list2：剩下的那段没接上，[1,2,4] + [1,3,5] 返回 [1,1,2,3,4]，少了 5。
    • 
    
  • 返回 dummy：答案前面多了一个假节点 0，返回 [0,1,1,2,3,4,5]。要返回 dummy.next。
    • 
    
  • 返回 tail：tail 在结果的最后面，只能读到最后一小段。
    • 
    
  • 循环条件写成 while list1 or list2：一条用完后还进循环，list1.val 在 None 上取值，报 AttributeError。
    •
