验证回文串

Valid Palindrome。这一页从“字符串的下标”讲起，依次讲清回文的定义、怎样判断字母数字、大小写统一、字符串切片，再到双指针，最后走到 O(n) 时间、O(1) 额外空间的最优解。每一章只讲一个前置知识，所有 Python 语法都会单独解释。

题目

给你一个字符串 s，如果它是回文串，返回 true，否则返回 false。

回文串是正着读和反着读都一样的字符串。本题判断时不区分大小写，并且忽略所有非字母数字字符。

字母数字字符指字母 A-Z、a-z 和数字 0-9。

输入: s = "Was it a car or a cat I saw?" 输出: true 解释: 只保留字母数字后是 "wasitacaroracatisaw"，是回文 输入: s = "tab a cat" 输出: false 解释: "tabacat" 不是回文

约束：1 ≤ s.length ≤ 1000，s 只包含可打印的 ASCII 字符。

01

字符串与下标

字符串就是一串字符排成一行，每个字符有一个下标，从 0 开始。空格和标点也是字符，同样占一个位置。s = "Race car!" 长这样（␣ 表示空格，格子上方是正数下标 / 负数下标）：

s = "Race car!"
len(s)          # 9，一共 9 个字符
s[0]            # "R"，第一个字符
s[len(s) - 1]   # "!"，最后一个字符
s[-1]           # "!"，负数下标从后往前数，-1 就是最后一个
  • len(s) 是长度。长度为 n 的字符串，下标是 0 到 n-1，所以最后一个字符的下标是 len(s) - 1。后面的右指针就从这里出发。
  • 访问 s[len(s)] 会报 IndexError: string index out of range，因为下标最大只到 len(s) - 1。第 07 章会遇到这个错误。
  • Python 里一个字符就是长度为 1 的字符串，单引号双引号都行："a" 和 'a' 一样。比较两个字符用 ==（相等）和 !=（不相等）。
  • 字符串不能原地修改：s[0] = "r" 会报错。想要一个“改过的”字符串，只能新建一个。第 05 章会用到这一点。
02

什么是回文

回文是正着读和反着读完全一样的字符串，比如 "level"、"abba"。换一种说法：把字符串从中间对折，每一对镜像位置上的字符都相同。

长度为 n 时，下标 i 的镜像位置是 n - 1 - i：第一个配最后一个，第二个配倒数第二个，以此类推。

回文 ⇔ 对所有 i < n / 2，都有 s[i] == s[n - 1 - i]
字符串是回文？原因
"level"是奇数长度，两两配对后正中间的 v 剩下，它和自己对称，不用比。
"abba"是偶数长度，正好两两配对，没有中间字符。
"abca"否第 2 对是 b 和 c，不相同。
"a"是只有一个字符，没有需要比较的对。
""是空字符串也没有需要比较的对，算作回文。像 ".," 这种全是标点的输入，清洗后就是空字符串。

试试 Abba 和 race car：按上面的纯定义，它们都不是回文，因为 A 和 a 是不同的字符，空格也只在一边。可这道题要求不区分大小写、忽略空格标点，这两个都应该返回 true。接下来两章分别解决“忽略哪些字符”和“大小写”。

03

字母数字：isalnum

题目只看字母数字字符（alphanumeric）：26 个大写字母、26 个小写字母、10 个数字。空格、逗号、问号、冒号、下划线等等都要忽略。

Python 的字符串自带一个方法 c.isalnum()：c 是字母或数字时返回 True，否则返回 False。“方法”就是跟在一个值后面、用点号调用的函数。

"a".isalnum()   # True
"7".isalnum()   # True
",".isalnum()   # False
" ".isalnum()   # False，空格不算
"_".isalnum()   # False，下划线也不算

在下面输入任意字符串，绿色是会被保留的字符，灰色划掉的是要忽略的。点任意一个格子，看 Python 怎么判断它：

不用 isalnum，自己写一个

面试官有时会要求不用内置函数。计算机里每个字符都对应一个整数编号，叫 ASCII 码，ord(c) 能取出这个编号。在 ASCII 表里，数字、大写字母、小写字母各自连续排列：

类别字符ASCII 码
数字"0" 到 "9"48 到 57
大写字母"A" 到 "Z"65 到 90
小写字母"a" 到 "z"97 到 122
其他（举例）空格、"!"、","、"?"、"_"32、33、44、63、95

所以只要判断编号是否落在这三段之一：

def alphaNum(c):
    return (ord("A") <= ord(c) <= ord("Z") or
            ord("a") <= ord(c) <= ord("z") or
            ord("0") <= ord(c) <= ord("9"))
  • a <= x <= b 是 Python 的连续比较，等价于 a <= x and x <= b，意思是 x 在 a 和 b 之间（含两端）。
  • or：只要有一边为真，结果就是真。三段里满足任意一段就是字母数字。
  • 最外层的圆括号让一个表达式可以跨多行书写，Python 会把括号里的内容当成一行。

Python 的 isalnum() 对中文、带重音的字母等也会返回 True。本题约束只有 ASCII 字符，所以两种写法的结果完全一样。

04

大小写：lower

题目要求不区分大小写，"W" 和 "w" 要当成同一个字符。最简单的办法：比较之前，两边都转成小写。

写法结果说明
"W".lower()"w"大写变小写
"w".lower()"w"本来就是小写，不变
"7".lower()"7"数字和标点没有大小写，不变
"Was It".lower()"was it"整个字符串可以一起转
  • lower() 返回一个新字符串，原来的不变（第 01 章说过字符串不能原地修改）。执行 c.lower() 之后 c 还是大写，要用它的返回值。
  • 大写字母和对应小写字母的 ASCII 码正好差 32：ord("a") - ord("A") 是 32。lower() 做的事，本质上就是把 65–90 映射到 97–122。
  • 全转大写 upper() 也可以，只要两边用同一种。

常见错误：只把一边转小写，比如 s[l].lower() != s[r]。遇到 "aA" 时，左边是 "a"，右边还是 "A"，会被误判为不相等。

05

解法一：清洗后反转

最直接的思路：先把 s 清洗成一个只含小写字母数字的新字符串，再看它和自己的反转是否相同。

newStr = ""
for c in s:
    if c.isalnum():                # 只要字母和数字
        newStr += c.lower()        # 统一成小写，拼到末尾
return newStr == newStr[::-1]      # 和自己的反转比较
  • newStr = "" 是空字符串。newStr += x 把 x 拼到末尾，等价于 newStr = newStr + x（每次都生成一个新字符串）。
  • == 比较两个字符串是否完全相同，结果是 True 或 False，可以直接 return。
  • newStr[::-1] 是 newStr 倒过来的字符串，下面讲。

切片：s[起点:终点:步长]

切片从字符串里截出一段，方括号里三个数分别是起点、终点（不包含）、步长，都可以省略。起点和终点都省略表示整段；步长写 -1 表示从后往前一个一个取。以 t = "abcde" 为例：

写法结果说明
t[1:4]"bcd"取下标 1、2、3，不含 4
t[:2]"ab"起点省略，从头开始
t[::2]"ace"步长 2，隔一个取一个
t[::-1]"edcba"步长 -1，整段倒过来

一行写法：推导式与 join

t = "".join(c.lower() for c in s if c.isalnum())
return t == t[::-1]
  • c.lower() for c in s if c.isalnum() 读作：“对 s 里的每个 c，如果它是字母数字，就取 c.lower()”。这种写法叫推导式，外面加上方括号 [...] 就得到一个列表。
  • "".join(一串字符串) 用前面那个字符串当“胶水”，把它们按顺序粘成一个。这里胶水是空串，所以直接首尾相接。对比："-".join(["a", "b"]) 得到 "a-b"。

输入任意字符串，看清洗和反转的结果（绿色是两行对应位置相同，红色是不同）：

结果：True
s（灰色划掉的字符会被丢掉）
t：只留字母数字，转小写
t[::-1]：t 倒过来

这个解法正确，时间 O(n)。但它新建了 t 和 t[::-1] 两个长度最多为 n 的字符串，额外空间 O(n)；而且必须先把整个字符串清洗完，才能开始比较。能不能不建新字符串、边走边比？这就是下一章的双指针。

06

双指针：从两头往中间走

双指针就是用两个变量记住两个下标。这里左指针 l 从最左边出发，右指针 r 从最右边出发，每比较完一对，两个指针一起往中间挪一格。它做的事和第 02 章的“镜像配对”完全一样，只是不用每次去算 n - 1 - i。

先假设字符串 t 已经是干净的（只有小写字母数字）：

l, r = 0, len(t) - 1
while l < r:
    if t[l] != t[r]:
        return False
    l, r = l + 1, r - 1
return True
  • while 条件: 只要条件为真，就一直重复下面缩进的代码，每一轮开始前都会重新检查条件。和 for 不同，while 不需要事先知道要循环几次。
  • l, r = 0, len(t) - 1 是同时赋值：先把右边的值全部算好，再按顺序交给左边的变量。l, r = l + 1, r - 1 就是“l 加一、r 减一”，等价于分两行写 l += 1 和 r -= 1。
  • 一旦发现一对不相等，立刻 return False，函数马上结束，后面的不用再看。这是比解法一好的另一点：可以提前结束。

用 t = "racecar"（n = 7）手动走一遍：

轮次lrt[l]t[r]结果
106rr相等，l、r 往中间走
215aa相等
324cc相等
结束33都指向 el < r 不成立，循环结束，return True

为什么是 l < r，而不是 l <= r

l == r 时两个指针指着同一个字符（奇数长度的正中间），自己和自己一定相等，没必要比。写成 l <= r 结果也对，只是多比较一次。l > r 说明两个指针已经交错，所有的对都比完了；偶数长度的 "abba" 就是在 l = 2、r = 1 时结束的。

额外空间：只用了 l 和 r 两个整数变量，没有新建字符串，所以是 O(1)。

07

跳过标点：内层循环与守卫

回到没清洗过的原始字符串。如果直接在 s = "race car" 上用上一章的代码，会怎样？

lrs[l]s[r]结果
07rr相等
16aa相等
25cc相等
34e␣ 空格不相等，return False（错了）

"race car" 清洗后是 "racecar"，正确答案是 True。问题在于空格只出现在一边，把镜像位置打乱了。办法是：每次比较之前，让两个指针各自先跳过要忽略的字符，停在下一个字母或数字上。

while l < r and not s[l].isalnum():   # 左指针：遇到要忽略的就往右挪
    l += 1
while l < r and not s[r].isalnum():   # 右指针：遇到要忽略的就往左挪
    r -= 1
  • not 把真假反过来。not s[l].isalnum() 的意思是“s[l] 不是字母数字”。整句读作：只要 s[l] 是要忽略的字符，就把 l 往右挪一格。
  • 这里必须用 while 而不是 if：可能连着好几个要忽略的字符，比如 ", "（逗号加空格），要一直跳到字母数字为止。
  • 左指针往右走（l += 1），右指针往左走（r -= 1），方向不能写反。

守卫 l < r：为什么内层也要写

A and B 只有两边都为真才是真，而且 Python 从左往右算：A 为假时结果已经确定是假，根本不会去算 B。这叫短路。内层的 l < r 就是靠短路，在 l 追上 r 时挡住后面的 s[l]。看看去掉它，对 s = "!!!" 会发生什么：

步骤l发生了什么
10s[0] 是 "!"，跳过，l 变成 1
21s[1] 是 "!"，跳过，l 变成 2
32s[2] 是 "!"，跳过，l 变成 3
43去读 s[3]，字符串只有 3 个字符，报 IndexError: string index out of range

加上守卫之后，l 最多走到和 r 相等就停，不会越界，也不会越过 r 跑进已经比较过的区域。

再走一遍 "race car"

轮次lr发生了什么
107都是字母，不用跳。r 和 r 相等，往中间走
216a 和 a 相等
325c 和 c 相等
434s[3] 是 e，左指针不动；s[4] 是空格，右指针跳过，r 变成 3
33r 追上 l，守卫让右指针停下。e 和自己比较，相等，然后 l = 4，r = 2
结束42l < r 不成立，return True

三块拼起来就是最终解法：外层 while 管“还有没有没比较的对”，两个内层 while 管“跳过要忽略的字符”，中间的 if 管“不区分大小写地比较”。下一章逐行单步看。

class Solution:
    def isPalindrome(self, s: str) -> bool:
        l, r = 0, len(s) - 1                       # 左右指针

        while l < r:
            while l < r and not s[l].isalnum():    # 左指针跳过要忽略的字符
                l += 1
            while l < r and not s[r].isalnum():    # 右指针跳过要忽略的字符
                r -= 1
            if s[l].lower() != s[r].lower():       # 不区分大小写比较
                return False
            l, r = l + 1, r - 1                    # 一起往中间走

        return True


class Solution {
    public boolean isPalindrome(String s) {
        int l = 0, r = s.length() - 1;

        while (l < r) {
            while (l < r && !Character.isLetterOrDigit(s.charAt(l))) l++;
            while (l < r && !Character.isLetterOrDigit(s.charAt(r))) r--;
            if (Character.toLowerCase(s.charAt(l)) != Character.toLowerCase(s.charAt(r))) {
                return false;
            }
            l++;
            r--;
        }
        return true;
    }
}


class Solution {
public:
    bool isPalindrome(string s) {
        int l = 0, r = (int)s.size() - 1;

        while (l < r) {
            while (l < r && !isalnum(s[l])) l++;
            while (l < r && !isalnum(s[r])) r--;
            if (tolower(s[l]) != tolower(s[r])) {
                return false;
            }
            l++;
            r--;
        }
        return true;
    }
};

  
第一行 class Solution: 和 def isPalindrome(self, s: str) -> bool: 是 NeetCode 给定的外壳。s: str 表示参数 s 是字符串，-> bool 表示返回 True 或 False，这些只是提示，不影响运行。如果面试要求不用 isalnum，把 s[l].isalnum() 换成第 03 章的 alphaNum(s[l]) 即可。

  
复杂度

  

    
解法时间额外空间原因

    
清洗后反转O(n)O(n)新建了 t 和 t[::-1]

    
双指针O(n)O(1)只用了 l、r 两个变量

  

  
双指针里有嵌套的 while，为什么不是 O(n²)？因为 l 只会增加、r 只会减少，而且两者永远不会越过对方。不管循环怎么嵌套，两个指针加起来最多一共走 n 步，每个字符最多被看一次。数复杂度时要看“总共做了多少事”，而不是数有几层循环。

  
最容易写错的四个地方

  
    
    
  • 内层 while 没写守卫 l < r："!!!"、".," 这种全是标点的字符串会越界报 IndexError。
    • 
    
  • 忘了 lower()，或者只转了一边："Aa"、"aA" 会被误判为不是回文。
    • 
    
  • 用 isalpha() 代替 isalnum()：isalpha 只认字母，数字被丢掉。"0P" 会只剩 "P"，误判为回文；正确答案是 False。
    • 
    
  • 比较完忘了移动指针：漏写 l, r = l + 1, r - 1，外层循环永远停不下来。
