有效的括号

Valid Parentheses。这一页从“怎样一个一个读字符串里的字符”讲起，依次讲清 Python 的列表、栈、字典和布尔判断，最后走到 O(n) 的最优解。每一章只讲一个前置知识，所有 Python 语法都会单独解释。

题目

给你一个只包含 ( ) [ ] { } 的字符串 s，判断它是否有效。有效需要同时满足：

  • 每个左括号都被同类型的右括号闭合。
  • 左括号按正确的顺序闭合。
  • 每个右括号都有一个对应的、同类型的左括号。
输入: s = "[]" 输出: true 输入: s = "([{}])" 输出: true 输入: s = "[(])" 输出: false

约束：1 ≤ s.length ≤ 1000。

01

字符串与逐字符遍历

字符串就是一串字符排成一行，和数组一样每个字符有一个下标，从 0 开始。s = "([{}])" 长这样：

Python 里有两种常见的遍历写法：

for c in s:              # 直接拿到每个字符，c 依次是 "(", "[", "{", ...
    print(c)

for i in range(len(s)):  # 拿到下标 i，再用 s[i] 取字符
    print(i, s[i])
  • len(s) 是字符串的长度，这里是 6。
  • for c in s 里的 c 是一个你自己起的变量名，每循环一次，它就变成下一个字符。本题不需要下标，所以用这种更简洁的写法。
  • Python 里一个字符就是长度为 1 的字符串，写作 "(" 或 '('，单引号双引号都行。比较两个字符是否相同用 ==，例如 c == "("。
02

什么叫“有效”

把括号想成盒子：左括号是打开一个盒子，右括号是关上一个盒子。有效的意思是：

  • 关盒子时，关的必须是最近打开、还没关上的那个盒子。
  • 盒子的类型要一致：圆盒子 ( 只能用 ) 关。
  • 最后所有盒子都关上了，没有剩下的。
字符串结果原因
"()[]{}"有效三个盒子并排，各开各关。
"([{}])"有效盒子套盒子，从里往外依次关上。
"(]"无效打开的是圆盒子，却用方括号去关，类型不对。
"[(])"无效最近打开的是 (，却先关了 ]，顺序不对。
"(("无效读完了，还有盒子没关。
")("无效一上来就关盒子，可是根本没有打开的盒子。

关键词是“最近打开的”。下一章会看到，正是这一点让简单的计数失效，也正是这一点指向了“栈”。

03

为什么数个数不够

很多人的第一反应是：数一数每种左括号和右括号的个数，个数相等就有效。看 "[(])"：

类型左括号个数右括号个数相等？
( )11相等
[ ]11相等

个数全部相等，但它是无效的。计数只记住了“有几个”，丢掉了“谁先谁后”。而这道题恰恰要求：遇到右括号时，能立刻知道最近一个还没配对的左括号是什么。

我们需要一个容器，能做到：放进去的东西按顺序排着，并且随时能拿到最后放进去的那一个。这个容器叫栈。在 Python 里，用列表就能当栈用，所以先学列表。

04

Python 列表的基本操作

列表（list）是 Python 里最常用的容器，用方括号写：stack = [] 表示一个空列表，stack = ["(", "["] 表示里面有两个元素。本题只用到下面五个操作：

写法作用例子（stack = ["(", "["]）
stack.append(x)把 x 加到列表末尾stack.append("{") 后变成 ["(", "[", "{"]
stack.pop()删掉末尾的元素，并把它返回返回 "["，列表变成 ["("]
stack[-1]看一眼末尾的元素，不删除得到 "["，列表不变
len(stack)元素个数得到 2
not stack列表为空时是 True得到 False（不为空）

负数下标 -1 是什么意思

Python 允许用负数从后往前数：-1 是最后一个，-2 是倒数第二个。所以 stack[-1] 和 stack[len(stack) - 1] 是一回事，只是更短。

两个会报错的情况：对空列表调用 pop() 会抛出 IndexError: pop from empty list；对空列表取 stack[-1] 会抛出 IndexError: list index out of range。所以取之前一定要先确认列表不为空，第 07 章会讲怎么写。

05

栈：后进先出

栈（stack）是一种只能在一头放和拿的容器，像一摞盘子：新盘子放在最上面，拿也只能从最上面拿。最后放进去的最先拿出来，叫后进先出（LIFO，Last In First Out）。

  • 放进去叫入栈（push），Python 写 stack.append(x)。
  • 拿出来叫出栈（pop），Python 写 stack.pop()。
  • 只看不拿叫查看栈顶（peek），Python 写 stack[-1]。

列表的“末尾”就是栈的“顶部”。点按钮亲手操作一下，下方会显示对应的 Python 语句和结果：

栈底

和括号对上号：遇到左括号就入栈（打开一个盒子）；遇到右括号就看栈顶，栈顶正好是“最近打开、还没关上”的那个左括号。这就是第 02 章那个关键词的实现方式。

06

字典：右括号查左括号

遇到右括号 ) 时，我们要知道“它应该配哪个左括号”。可以写一串 if：

if c == ")":
    want = "("
elif c == "]":
    want = "["
elif c == "}":
    want = "{"

能用，但啰嗦。更好的工具是字典（dict）：它存的是一对一对的“键 → 值”，给出键就能查到值，像查字典一样。

closeToOpen = {")": "(", "]": "[", "}": "{"}
  • 字典用花括号写，每一对写成 键: 值，对与对之间用逗号隔开。这里键是右括号，值是对应的左括号。
  • closeToOpen[")"] 用键查值，得到 "("。查一个不存在的键会报 KeyError。
  • c in closeToOpen 判断 c 是不是字典的键，返回 True 或 False。注意 in 只看键，不看值，所以 "(" in closeToOpen 是 False。

一个字典同时帮我们做了两件事：用 in 区分左右括号，用 [ ] 查出该配的左括号。点一个字符试试：

变量名 closeToOpen 是 NeetCode 的写法，意思是“close（右括号）到 open（左括号）的映射”。名字你可以随便起，比如 pairs，好的名字能让人一眼看出键和值分别是什么。

07

真假判断与 and 短路

列表本身就能当真假用

在 if 后面放一个列表，Python 会把空列表当成 False，非空列表当成 True：

stack 的值if stack:not stack等价写法
[]不进入Truelen(stack) == 0
["("]进入Falselen(stack) != 0

所以最后一行 return not stack 的意思是：“栈空了就返回 True，没空就返回 False”。not 把真假反过来。

and 的短路

A and B 只有两边都为真才是真。关键在于 Python 从左往右算，一旦 A 是假，结果已经确定是假，根本不会去算 B。这叫短路。

if stack and stack[-1] == closeToOpen[c]:
    stack.pop()

当 stack 为空时，左边 stack 是假，右边的 stack[-1] 不会执行，也就不会报 IndexError。顺序不能反：写成 stack[-1] == ... and stack，空栈时会先执行 stack[-1]，直接报错。

return 会立刻结束函数

函数里一旦执行到 return False，后面的代码（包括循环剩下的部分）都不再执行。发现一处错误就能马上下结论，不用把字符串读完。

08

算法思路与三种失败

把前面的知识拼起来，从左到右读每个字符 c：

  1. c 是左括号（不在字典的键里）：入栈，stack.append(c)。
  2. c 是右括号（在字典的键里）：
    • 如果栈不空，并且栈顶正好是 closeToOpen[c]：配对成功，出栈。
    • 否则：立刻 return False。
  3. 读完所有字符：栈空就有效，return not stack。

无效只有三种可能，每一种都对应代码里的一个位置：

失败原因例子代码在哪里发现
右括号来了，栈是空的")("、"())"if stack 为假 → return False
右括号和栈顶类型不配"(]"、"[(])"stack[-1] == closeToOpen[c] 为假 → return False
读完了栈里还有左括号"(("、"{[]"最后 not stack 为假

小优化：长度为奇数的字符串一定无效，因为括号总是成对出现。可以在开头加 if len(s) % 2 == 1: return False（% 是取余数）。不加也完全正确。

class Solution:
    def isValid(self, s: str) -> bool:
        stack = []                                  # 用列表当栈
        closeToOpen = {")": "(", "]": "[", "}": "{"}  # 右括号 → 左括号

        for c in s:
            if c in closeToOpen:                    # c 是右括号
                if stack and stack[-1] == closeToOpen[c]:
                    stack.pop()                     # 配对成功，出栈
                else:
                    return False                    # 栈空或类型不配
            else:                                   # c 是左括号
                stack.append(c)                     # 入栈

        return not stack                            # 栈空才有效


class Solution {
    public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        Map<Character, Character> closeToOpen = Map.of(')', '(', ']', '[', '}', '{');

        for (char c : s.toCharArray()) {
            if (closeToOpen.containsKey(c)) {
                if (!stack.isEmpty() && stack.peek().equals(closeToOpen.get(c))) {
                    stack.pop();
                } else {
                    return false;
                }
            } else {
                stack.push(c);
            }
        }
        return stack.isEmpty();
    }
}


class Solution {
public:
    bool isValid(string s) {
        stack<char> st;
        unordered_map<char, char> closeToOpen = {{')', '('}, {']', '['}, {'}', '{'}};

        for (char c : s) {
            if (closeToOpen.count(c)) {
                if (!st.empty() && st.top() == closeToOpen[c]) {
                    st.pop();
                } else {
                    return false;
                }
            } else {
                st.push(c);
            }
        }
        return st.empty();
    }
};

  
第一行 class Solution: 和 def isValid(self, s: str) -> bool: 是 NeetCode 给定的外壳。s: str 表示参数 s 是字符串，-> bool 表示函数返回 True 或 False，这些只是提示，不影响运行。

  
复杂度

  
    
    
  • 时间 O(n)：每个字符只看一次，每次的 append、pop、stack[-1]、字典查找都是常数时间。
    • 
    
  • 空间 O(n)：最坏情况是全是左括号，例如 "(((("，栈里要放 n 个元素。这道题不存在更省空间的通用解法，所以这就是最优解。
    • 
  

  
最容易写错的四个地方

  
    
    
  • 忘了判空：直接写 if stack[-1] == closeToOpen[c]，遇到 ")" 开头的字符串会报 IndexError。
    • 
    
  • and 两边顺序写反：必须先写 stack 再写 stack[-1]，靠短路保护。
    • 
    
  • 最后直接 return True："((" 会被误判为有效。要写 return not stack。
    • 
    
  • 字典方向写反：写成 {"(": ")", ...}，那 c in closeToOpen 判断的就变成了左括号，后面整套逻辑都要跟着改。
